# 台灣鄉鎮制霸地圖

記錄你去過的台灣鄉鎮，順便認識各地的美食、景點與節慶的互動式網頁。

- 依「路過／玩過／過夜／住過」為 368 個鄉鎮市區打卡上色
- 點開縣市或鄉鎮，就能看到當地特色
- 集滿一個縣市可以獲得郵戳徽章，收進「我的護照」
- 可以搜尋地名或特色（例如「肉圓」），也能隨機推薦下一站

整個網站只有一個 `index.html`，直接用瀏覽器開啟即可使用（需要網路來載入函式庫與字型）。打卡紀錄只會存在自己的瀏覽器中。

規格與討論過程請見 [規格書.md](規格書.md)。

## 資料來源
- 地圖：內政部國土測繪中心「鄉鎮市區界線」開放資料，經 [taiwan-atlas](https://github.com/dkaoster/taiwan-atlas) 轉換
- 各地特色：在 AI 協助下整理，僅供參考
